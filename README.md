# Experiment700

Live at **[experiment700.github.io](https://experiment700.github.io)**.

Marketing site, privacy policy, and documentation for Hazard Intelligence — a real-time human safety platform for iOS.

## What's here

- `index.html` — landing page
- `privacy/` — privacy policy (canonical URL referenced by App Store)
- `style.css`, `app.js` — site styling and animated topo background
- `404.html` — branded not-found page
- `assets/` — image and media assets

## Deployment

Hosted via GitHub Pages from the `main` branch. Pushes to `main` deploy automatically within a few minutes.
